# swahili-civic-nlp (discontinued)

> **Status, 2026-10-17: discontinued. This repository never contained data.**
>
> It was started to hold Swahili civic-language resources (constitutional rights, government services, M-PESA terms). None were ever published. The Hugging Face and Kaggle datasets of the same name held only a README, and were deleted on 2026-10-17. Nothing here is a dataset, a model or a toolkit.
>
> The DPGA submission GID0093743 described a dataset that does not exist and should be withdrawn.

## Why it was started

Civic and legal Swahili is poorly covered by general-purpose corpora. That remains an open problem; this repository did not address it.

## If you want to build it

Real data would need official Swahili texts, a licence check on each source and review by native speakers. Start a new repository for that; do not rely on anything here.
