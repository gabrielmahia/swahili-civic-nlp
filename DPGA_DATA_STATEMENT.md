# Data statement: swahili-civic-nlp (DPGA GID0093743), WITHDRAWN

As of 2026-10-17 this project has **no dataset, no model and no toolkit**. The repository never contained data, and the Hugging Face and Kaggle datasets of the same name held only a README and were deleted.

Earlier versions of this file described dataset contents (constitutional rights explanations, government service descriptions, M-PESA terms, legal process descriptions) and sources. Those descriptions did not correspond to any published data and have been removed. The submission should be withdrawn.
