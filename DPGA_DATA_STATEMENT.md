# Data Statement — swahili-civic-nlp (DPGA GID0093743)

## Architecture

`swahili-civic-nlp` is an open dataset and NLP toolkit, not a trained model.
It provides Swahili civic language resources for downstream NLP tasks.
No model is embedded or deployed.

## Dataset Contents

Civic Swahili text covering:
- Constitutional rights explanations
- Government service descriptions and navigation
- M-PESA terms and conditions in plain Swahili
- Legal process descriptions (land, labor, civic procedures)
- County government service information

## Data Sources and Licensing

All source text is either:
- Original civic language authored for this dataset (CC BY 4.0), or
- Public domain government documents (Kenya Constitution, Acts of Parliament)

No proprietary or paywalled sources are included.

## Open Training Data

This dataset is fully open and intended for use in training, fine-tuning, and
evaluation of NLP models for Swahili civic contexts. All data files are
available without registration or fee via HuggingFace (gmahia/swahili-civic-nlp).

Per the 2025 DPG Standard for AI systems: all data used in AI system development
must be open and available. This dataset meets that standard.

## Research Context

- AfricaNLP 2025/2026: Only 4 African languages have consistent NLP support
- Swahili civic/legal language is severely underrepresented even within those 4
- Healthcare and civic AI accuracy is identified as the highest-priority gap domain
